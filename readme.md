## 制作说明

参考文档:
[BolunHan/miui.eu.localization](https://github.com/BolunHan/miui.eu.localization) |
[Magisk Developer Guides](https://topjohnwu.github.io/Magisk/guides.html#magisk-modules)

- 如果使用小米钱包的公交卡（或者其它NFC功能），请先确认以下设置，如果刷卡无效可以试试先改为HCE再改回内置
  系统设置 -> `连接与共享` -> `安全模块位置` -> `内置安全模块`

- 小爱同学使用正常，语音唤醒正常，但是AI键唤醒无效

- 其它功能参考文档制作，没有实际使用

- 欢迎提交 [issue](https://github.com/kltk/miui.eu.localization/issues) [pull request](https://github.com/kltk/miui.eu.localization/pulls)
